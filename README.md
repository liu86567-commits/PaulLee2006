# Offer Pulse

Offer Pulse 是一个面向 **2027 届全职校园招聘、海外商务方向** 的个人岗位监控看板。

## 在线查看

- GitHub Pages: https://liu86567-commits.github.io/PaulLee2006/
- Cloudflare Pages: https://offerpulse-cv4.pages.dev/

## 当前能力

- 每日抓取公开校招线索，并严格排除实习、社招、校园大使、宣讲和已过期岗位
- 按“今日更新 / 近两日更新 / 全部岗位”交互筛选
- 支持公司、岗位、地区和海外商务关键词搜索
- 对官网岗位与聚合线索做清晰标记
- 按海外、国际、商务、销售、市场、运营、渠道、供应链等方向评分
- 本地定时任务每日更新并发送个人邮件日报

## 数据说明

聚合站仅用于发现线索；投递前应以公司招聘官网为准。公开仓库不包含 Cookie、邮箱授权码、Cloudflare 密钥、个人简历或其他私人配置。

## 简历项目描述

> 独立设计并实现 Offer Pulse 校招岗位监控系统：整合公开招聘线索与企业官网核验，构建 2027 届海外商务岗位的自动抓取、严格过滤、优先级评分、交互式检索、静态站点发布及邮件日报流程。
